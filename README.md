## Avito Parser

**Avito Parser** — это инструмент для автоматического мониторинга новых объявлений на Avito, с возможностью мгновенной отправки уведомлений в Telegram и экспорта в Excel. Идеально подходит для продавцов, аналитиков и всех, кто следит за ценами и предложениями.


📜 **История изменений** — [смотреть](CHANGELOG.md)

### Возможности

#### 📌 Основные
- Мониторинг новых объявлений на Avito в реальном времени
- Выгрузка найденных объявлений в Excel
- Кроссплатформенность (Windows, Linux, macOS)

#### 🤖 Telegram-бот фильтров
- Инлайн-меню с шагами по добавлению фильтра: ключевые слова, регион, цены, доставка, трекинг цены и интервал (2–60 секунд)
- За один шаг можно перечислить несколько поисковых запросов (через запятую или с новой строки) и применить к ним общий фильтр
- Добавь кавычки вокруг запроса, если нужна точная фраза (например, `"айфон 16"`)
- Независимые задания для каждого фильтра — парсер запускается с заданной периодичностью и не блокирует остальные фильтры
- Уведомления в Telegram содержат фото, цену, ссылку, регион и пометку о наличии доставки, а также показывают изменения цены
- При первом запуске бот присылает аккуратный стартовый пакет объявлений, а дальше — отдельные карточки по мере появления новинок
- Бот умеет редактировать/удалять фильтры, отдельно переключать доставку и отслеживание цены и приветствует стикерами
- Cookies и история для каждого chat_id хранятся отдельно → блок одного пользователя не мешает остальным
- Кнопка «Скачать XLSX» в любой момент присылает актуальную выгрузку по всем вашим фильтрам

> Хотите отложить отправку уведомлений до второй проверки? Добавьте в `.env` переменную `SKIP_FIRST_NOTIFICATIONS=1`. По умолчанию уведомления приходят сразу.

#### ⚙️ Гибкие настройки
- Чёрный/белый список ключевых слов
- Фильтр по региону и продавцам
- Ограничение по времени публикации
- Парсинг количества просмотров
- Поддержка прокси (автоматический обход бана IP)

#### 📬 Уведомления и хранение
- Отправка уведомлений в Telegram (несколько получателей)
- Игнорирование уже просмотренных объявлений
- Отслеживание изменения цены

#### 🚀 Производительность
- Высокая скорость работы
- Постоянная проверка в фоновом режиме
- Поддержка до 100 ссылок для отслеживания (в режиме без графического интерфейса ограничений нет)

#### 🐳 Режимы запуска
- С графическим интерфейсом (GUI)
- В консольном режиме (CLI)
- В Docker-контейнере

### 🚀 Установка и запуск
На Windows 10, 11 запустить версию с графическим интерфейсом можно просто:

>- [Перейти в релизы](https://github.com/Duff89/parser_avito/releases)
>- Скачать самый свежий zip архив
>- Разархивировать в удобное место
>- Запустить AvitoParser.exe


Если по каким-то причинам предыдущий вариант не запускается - всегда можно запустить как обычный Python проект.
Для это требуется Python 3.11+. Скопируйте проект и установите зависимости:

```bash
  pip install -r requirements.txt
```

Запустите **AvitoParser.py** (режим с графическим интерфейсом)

```bash
  python AvitoParser.py
```

Если Вам необходимо запустить парсер на сервере (режим без графического интерфейса), запускайте:

```bash
  python parser_cls.py
```

Для одновременного запуска бота с планировщиком фильтров используйте общий раннер:

```bash
python service_runner.py
```

### Выгрузка XLSX из бота

Каждый пользователь получает отдельный файл `result/users/<chat_id>/monitoring.xlsx`, куда попадает всё, что найдено по его фильтрам (включая название фильтра, регион и интервал проверки в секундах).  
Чтобы скачать файл, нажмите кнопку **«Скачать XLSX»** в основном меню Telegram-бота или выполните команду `/xlsx`. Если это первый запуск и данных ещё нет — бот подскажет дождаться завершения очередного цикла.

## Работа через Docker

Перед использованием настройте `config.toml`

### Основные команды

```bash
make build    # собрать образ
make run      # запустить контейнер в фоне
make restart  # перезапустить контейнер
make rebuild  # пересборка: stop → build → run
make stop     # остановить и удалить контейнер
make logs     # показать логи
make shell    # подключиться внутрь контейнера
make clean    # удалить контейнер и образ
```
> Контейнер сразу поднимает service_runner.py, поэтому бот и планировщик фильтров доступны из коробки.  
> Логи приложения по умолчанию пишутся в `logs/app.log` внутри проекта.

### Docker Compose

Для постоянного развёртывания можно воспользоваться `docker-compose.yml`:

```bash
docker compose up -d         
docker compose logs -f parser 
docker compose down           
```

Сервис автоматически перезапускается (`restart: unless-stopped`), использует `.env` и шарит директорию проекта внутрь контейнера, поэтому логи и выгрузки доступны с хоста.
